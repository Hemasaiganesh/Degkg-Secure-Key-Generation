DeGKG Security Model & Formal Guarantees

Provable Security Under Standard Cryptographic Assumptions • Physical-Layer Entropy • Byzantine Fault Tolerance

🔎

Adversary Model Dolev-Yao + Active Adversary

Adversary Capabilities (Polynomial-Time Bounded):

  • ✓ Eavesdropping on all wireless communications (passive)
  • ✓ Injecting, modifying, or replaying messages (active)
  • ✓ Corrupting a subset of drones (≤ threshold)
  • ✓ Acting as malicious consensus participant (bounded Byzantine faults)

Adversary Limitations:

  • ✗ Cannot break standard cryptographic hash functions (preimage resistance)
  • ✗ Cannot solve DL/CDH/DDH in prime-order cyclic groups
  • ✗ Cannot replicate satellite SNR patterns within bounded geographic distance
  • ✗ Cannot exceed Byzantine fault threshold (f ≤ ⌊(n-1)/3⌋)
🔐

Confidentiality of Session Keys IND-CPA Secure

Intra-group keys are derived using fuzzy extractors applied to quantized satellite SNR vectors. Inter-group encryption follows an ElGamal-style construction over cyclic group G of prime order.

Inter-Group Encryption: c₁ = K_cr × (Kₑₙ)^s mod M, c₂ = g^s mod M

Security Reduction: Security reduces to the Decisional Diffie-Hellman (DDH) assumption. If an adversary distinguishes session keys with non-negligible advantage ε, it implies solving DDH with advantage ε, contradicting the hardness assumption.

👤

Source Authentication & Integrity HMAC-SHA256

All critical protocol messages include HMAC-SHA256 authentication tags and timestamps. This ensures message integrity, source authenticity, and freshness protection.

Authentication Tag: τ = HMAC-SHA256(K, message || timestamp || nonce)

Any modification alters the authentication tag with probability 1 - 2^(-256). Under PRF security of HMAC, forgery probability is negligible (≤ 2^(-128) for 256-bit keys).

⏩

Forward Secrecy Perfect Forward Secrecy

Session keys evolve using hash chain construction:

Key Evolution: Kᵢ = Rᵢ ⊕ SHA-256(Kᵢ₋₁)

Due to the one-way property of SHA-256 (preimage resistance), knowledge of Kᵢ does not allow computation of Kᵢ₋₁. Thus, compromise of the current key does NOT expose historical communication.

✅
Past Keys Protected
Compromise of Kᵢ reveals no previous keys
📐
One-Way Function

⏪

Backward Secrecy Future Key Unpredictability

Future keys depend on fresh satellite-derived randomness Rᵢ:

Fresh Entropy: Rᵢ = Rep(wᵢ, Pᵢ) where wᵢ = Gray(Quantize(SNRᵢ))

Since Rᵢ originates from unpredictable physical-layer entropy (satellite SNR measurements), knowledge of previous keys does NOT enable prediction of future keys. Each key update incorporates new high-entropy randomness (≥ 7.8 bits/byte).

🛰️

Physical-Layer Security Assumption Location-Dependent

Security assumes that nearby drones (geographically co-located) observe correlated satellite SNR vectors within bounded Hamming distance d(w, w') ≤ t, while distant adversaries observe statistically independent measurements.

Fuzzy Extractor Correctness: Rep(w', P) = R if d(w, w') ≤ t

If distance exceeds threshold (d(w, w') > t), the fuzzy extractor reproduction fails with probability ≥ 1 - 2^(-λ), preventing unauthorized key reconstruction by remote adversaries.

⛓️

Blockchain Consensus Correctness Byzantine Fault Tolerance

Inter-group encryption keys are validated through Byzantine fault-tolerant consensus among Ground Control Stations (GCS nodes). Security properties:

  • Agreement: All honest nodes agree on the same key
  • Validity: Agreed key is valid under protocol rules
  • Termination: Consensus completes in finite time
Fault Tolerance: Correctness guaranteed if f ≤ ⌊(n-1)/3⌋ malicious nodes

Under the Byzantine fault model, the blockchain provides an immutable, tamper-proof ledger of all inter-swarm key agreements.

Formal Proof Summary

Theorem 1 (Key Indistinguishability): Under DDH assumption in group G, any PPT adversary has negligible advantage in distinguishing DeGKG session keys from random.
Theorem 2 (Authentication Security): Under PRF security of HMAC, forgery probability ≤ 2^(-128) for 256-bit keys.
Theorem 3 (Forward Secrecy): If SHA-256 is preimage-resistant, compromise of Kᵢ does not reveal Kᵢ₋₁.
