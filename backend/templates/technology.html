Gray Code Encoding Error Minimization
Quantized signals are converted to Gray codes where consecutive values differ by exactly one bit. This minimizes bit errors during transmission and preserves signal similarity for fuzzy extraction.
📐 Property: Hamming distance between adjacent values = 1 • Error correction rate ↑ 40%

Fuzzy Extractor Dodis et al. 2004
Transforms similar but non-identical satellite signals into identical cryptographic keys without transmitting secret material. Corrects bounded Hamming distance errors (t ≤ 15% of length).

SHA-256 Cryptographic Hash NIST Standard
Provides preimage resistance and collision resistance for key evolution. Ensures forward secrecy (Kᵢ₋₁ cannot be derived from Kᵢ) and backward secrecy (future keys unpredictable).
Key Evolution: Kᵢ = Rᵢ ⊕ SHA-256(Kᵢ₋₁) • 256-bit output

HMAC-SHA256 RFC 2104
Provides message authentication with provable security under PRF assumptions. Prevents replay attacks, message tampering, and impersonation using timestamps and nonces.
τ = HMAC-SHA256(K, msg || timestamp || nonce) • 256-bit tag
