🔐 DeGKG: Efficient Decentralized Inter-Group Key Generation for Drone Swarms
IEEE TON • 2026
Liu, G., Zhang, Y., Wang, Q., & Chen, X.
10.1109/TON.2025.3649750
This seminal work proposes a two-layer decentralized key architecture integrating satellite signal entropy, fuzzy extraction, Chinese Remainder Theorem aggregation, and blockchain consensus. It simultaneously addresses intra-swarm and inter-swarm secure communication without reliance on a trusted authority, achieving O(m) complexity where m is the number of swarms.

Advantages

  • First architecture supporting decentralized inter-swarm key aggregation
  • Reduces complexity from O(n) to O(m) (drones → swarms)
  • Formal reduction to DL/CDH/DDH assumptions
  • Achieves forward & backward secrecy

Limitations

  • Requires blockchain-enabled GCS infrastructure
  • Classical cryptographic (not post-quantum secure)
  • Blockchain latency in ultra-constrained environments
Research Positioning: DeGKG serves as the foundational framework for this project, providing the core cryptographic primitives and architectural blueprint.
📡 EGKC: Satellite-Based Group Key Creation for Drone Swarms
IEEE TIFS • 2021
Wang, H., Li, J., & Zhang, Y.
10.1109/TIFS.2021.3080234
EGKC demonstrates that geographically co-located drones observe correlated satellite SNR values and can independently derive identical keys without transmitting secret material, leveraging physical-layer entropy from GPS, BeiDou, and Galileo constellations.

Advantages

  • No key exchange over network (passive derivation)
  • Physical-layer entropy exploitation from satellite signals
  • Resistance to passive eavesdropping

Limitations

  • Limited to single-swarm environments
  • No inter-group coordination mechanism
  • Vulnerable to GPS spoofing attacks
Positioning: DeGKG extends EGKC by enabling multi-swarm key aggregation via CRT and adding blockchain-based inter-swarm coordination.
🔑 Fuzzy Extractors: A Foundation for Cryptographic Key Generation from Noisy Data
IACR ePrint • 2004
Dodis, Y., Reyzin, L., & Smith, A.
IACR ePrint 2004/086
Provides theoretical framework for deriving stable cryptographic keys from noisy biometric or physical inputs. Guarantees correctness if Hamming distance is within threshold t, enabling error-tolerant key generation.

Advantages

  • Provable correctness under bounded noise
  • Information-theoretic key stabilization
  • Widely adopted in physical-layer security

Limitations

  • Requires helper data broadcast (public channel)
  • Entropy loss during extraction
Positioning: DeGKG applies fuzzy extractors to satellite-derived SNR entropy, ensuring stable key generation despite signal variations.
🧮 Chinese Remainder Theorem & Its Applications in Cryptography
Classical • c. 3rd Century CE
CRT enables reconstruction of integers from residues under pairwise co-prime moduli. In modern cryptography, it enables efficient RSA decryption, secret sharing, and multi-party computation. DeGKG leverages CRT for aggregating multiple swarm public keys into a single compact encryption parameter.

Advantages

  • Enables scalable multi-key aggregation
  • Reduces inter-swarm communication overhead
  • O(m) complexity vs O(n) alternatives

Limitations

  • Requires strict co-prime modulus management
  • Modulus size grows with number of swarms
Positioning: CRT transforms swarm-level public keys into a unified encryption key enabling efficient inter-swarm communication.
⛓️ Practical Byzantine Fault Tolerance (PBFT)
OSDI • 1999
Castro, M., & Liskov, B.
PBFT introduced the first practical state machine replication protocol tolerating Byzantine faults. It ensures consensus even with up to f malicious nodes where f ≤ ⌊(n-1)/3⌋, providing the foundation for modern blockchain systems.

Advantages

  • Eliminates single point of failure
  • Decentralized trust model
  • Finality without forks

Limitations

  • Adds latency to key synchronization
  • Requires infrastructure overhead
  • Communication complexity O(n²)
Positioning: DeGKG integrates BFT consensus for decentralized validation and immutable key registry.
